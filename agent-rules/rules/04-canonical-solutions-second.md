# Pass 2: canonical solutions

Start only after the question roster and provisional evidence contracts pass their stage gate. Produce one canonical-solution document per accepted question. Prefer a documented open-source route where suitable; existing platforms are allowed when versions, access/license costs, prerequisites, constraints and alternatives are explicit.

Specify the desired effect, environment, component versions, prerequisites, authorized implementation steps, dependencies, resources with units/basis, rollback, verification steps, expected evidence and acceptable alternatives. Each verification step maps to the question's criterion. Purchasing/installing a named product does not satisfy the condition by itself. A canonical approach is a reference route, not a universal vendor mandate.

Use official current platform/maintainer documentation for commands and version behavior. Unknown measurements, prices, capabilities or execution outcomes remain unknown. An outline is not an execution-tested recipe. Keep `executionValidation` separate from semantic/source acceptance; never fabricate successful tool logs.

If a question cannot be achieved under the stated resources, report a justified blocker, a missing-information state, or 'no route found', rather than pretending impossibility or weakening the condition. A question defect returns to Pass 1; record dependency invalidation and recheck all affected artifacts.

The optional `qwen3-coder-next:q8_0` specialist reviews implementation details or prepares authorized sandboxed fixtures. It does not decide legal applicability or deploy real infrastructure merely because a solution was requested. Production execution needs its own declared task permissions; code examples stay proposals until observed verification exists.

In time-limited CI, solution work has Y minutes including its checks and bounded repairs. Token-budget mode instead charges paper Y; changed question work charges remaining paper X. Preserve sources, alternative implementations, unresolved assumptions, parent digests and stage decisions. Accepted solutions pass with unchanged contracts to Pass 3.
